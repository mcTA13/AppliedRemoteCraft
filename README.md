# Applied Remote Craft

NeoForge 1.21.1 addon for Applied Energistics 2 and AE2WTLib.

Install the **Remote Craft Card** in a Wireless Universal Terminal (inventory or Curios slot), then middle-click an item or fluid in JEI
(ingredient list, bookmarks, or recipe screen) to open the AE2 craft amount screen from anywhere.

## Requirements

- NeoForge 21.1.x (Minecraft 1.21.1)
- Applied Energistics 2 19.2.18+
- AE2WTLib 19.5.1+
- JEI 19.x (client)
